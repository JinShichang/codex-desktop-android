## 设备验收

1. 记录应用版本、桌面版本、后端版本和 Android ROM。覆盖升级前核对签名并保留原有项目、登录和运行环境。
2. 验证冷启动、登录回调、中文输入、竖横屏、键盘遮挡和显式退出。Android 的子进程额度由系统共享，需在实际使用条件下观察后台恢复。
3. 以测试项目检查消息回复、本地命令输出、文件写入和两个独立会话。共享目录工作区应使用实际已授权的路径。
4. 分别检查前台 MCP 的读屏和输入、用户接管与停止。将可选的 Root 后台屏和其他高权限通道单独验收。

记录实际输出和失败范围。主机检查、安装成功以及单次启动，分别只证明其对应的环节。 [构建指南](build.md) · [测试指南](../tests/README.md)
